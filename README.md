# Запись на встречу

Telegram Mini App и бот для согласования встреч с Дмитрием.

- Бот: https://t.me/FinDir41bot
- Приложение: https://lugovoy.shop/meet/
- Локальная демонстрация и запуск: [MINIAPP.md](MINIAPP.md)
- Требования: [ТЗ Mini App.md](ТЗ%20Mini%20App.md)
- Результат: [Результат Mini App.md](Результат%20Mini%20App.md)
- Этапы: [План Mini App.md](План%20Mini%20App.md)
- Первоначальная документация бота: [README_BOT.md](README_BOT.md)

Google-аккаунт владельца пока не подключён. Рабочее приложение не предлагает непроверенные слоты и не создаёт встречи без Google. Для локальной проверки есть отдельный деморежим без реальных данных и сообщений.

API и Telegram работают в одном процессе с общей SQLite и блокировкой операций. На сервере используется systemd, HTTP доступен только через nginx/HTTPS.

Секреты, пользовательские данные и логи не входят в репозиторий.
