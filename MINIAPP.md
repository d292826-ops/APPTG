# Запись на встречу — Telegram Mini App

Приложение дополняет @FinDir41bot. Google подключается отдельно владельцем; без него рабочая запись закрыта.

## Локальная демонстрация

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python demo.py
```

Открыть:

- Пользователь: http://127.0.0.1:8088/meet/demo/user
- Администратор: http://127.0.0.1:8088/meet/demo/admin

Демо слушает только loopback, использует временную SQLite, вымышленный календарь и не отправляет сообщения. После остановки демоданные удаляются. Не запускать demo.py на публичном адресе. В производственном приложении демовход запрещён независимо от cookies/URL.

## Рабочий запуск

Существующий bot.py запускает HTTP на 127.0.0.1:8087 при наличии MINIAPP_URL=https://lugovoy.shop/meet/. nginx проксирует только /meet/ на этот порт. Бот и API используют один Store, Scheduler и operation_lock; отдельный API-процесс запускать нельзя.

Telegram-токен хранится в серверном .env и не попадает в клиентский код или репозиторий. API проверяет initData и права. Не включайте содержимое .env, базы, Google-токены и логи в архивы исходников.

## Проверки

```sh
.venv/bin/python -m unittest discover -s tests -v
node --check miniapp/app.js
```

Проверки Google используют подмену API. Они не подтверждают работу настоящего календаря. Демонстрация не подтверждает реальное открытие из Telegram и мобильную верстку; это отдельные проверки.

## Сдача урока

После размещения проверить запуск кнопкой «Записаться» из бота, профиль, свои заявки и управление с аккаунта владельца. Без Google запись должна показывать сообщение о недоступности.

Кнопку нижнего меню можно настроить через Bot API setChatMenuButton. Отдельная кнопка профиля Main Mini App настраивается в @BotFather: /mybots → FinDir41bot → Bot Settings → Configure Mini App / Main Mini App → адрес приложения. Подписи могут отличаться между версиями BotFather; факт включения проверяется в Telegram.
